# Chess of Dark — IARC Rating Guide

## What is IARC?

The International Age Rating Coalition (IARC) provides age ratings for digital games across all major platforms. Steam uses IARC ratings for store compliance. The rating questionnaire takes approximately 10–15 minutes to complete.

**IARC Portal:** https://www.globalratings.com/

## Steam Store Setup

1. Go to Steamworks App Admin → Store Page → Ratings
2. Click "Manage Ratings" → "Complete Questionnaire"
3. Answer using the table above
4. Submit — IARC generates ratings automatically within minutes
5. Ratings appear on the store page before release
