- 최종 업데이트: 2026-09-23
- 플랫폼: PC Windows, 단일 HTML, Steam 출시 후보
- 최신 GDD: `ChessSummon_GDD.md`

## 제품 정의

5×5 보드에서 턴마다 얻는 마나로 체스 말을 소환하고 이동·포획·체크 압박을 조합하는 짧은 다크 판타지 전술 게임이다. 목표 사용자는 정통 체스보다 10~30분 안에 전술적 결론이 나는 체스 퍼즐·소환 전략을 선호하는 PC 게이머다.

## 핵심 문제와 MVP 가설

소환, 이동, 포획, 체크를 동시에 이해해야 하므로 행동 전에 결과와 위험이 한 화면에서 읽혀야 한다. `선택 → 예상 비교 → 실행 → 결과 → 다음 행동`이 끊기지 않으면 첫 판 이해도와 재대전 의도가 높아진다는 가설을 검증한다.

핵심 루프는 모드/난이도 선택 → 초기 배치 → 마나 획득 → 이동/포획 → 선택적 소환 → 턴 종료 → 왕 제거/체크메이트 → 결과·MMR·전술 복기 → 다음 소환/편성 판단 → 재대전이다.

## 2026-09-23 결과→다음 전투 개선

결과 화면은 남은 마나, 소환 횟수, 양측 잔존 전력을 바탕으로 다음 판에 시험할 행동 하나를 제시한다. 주력 말을 소환하지 못했다면 기사·주교 중 하나를 첫 소환으로 정하고, 전력 열세였다면 병사 1개를 후속 소환 거점으로 보존하며, 승리했다면 가장 많이 사용한 주력 소환 전개를 유지하도록 안내한다. 기존 결과 프레임과 텍스트 계층을 확장했으며 새 이미지 자산은 사용하지 않았다.

## 2026-09-22 목표 화면과 구현

예시 화면은 `docs/design-references/2026-09-22-move-threat-board-preview.png`다. 기존 보드와 HUD를 유지하면서 아군 말 선택 시 모든 합법 목적지에 `안전`, `교환`, `위험`을 표시하고, 포획은 `처치 · 상태`로 구분한다. HUD는 `이동4 안전2 위험1 처치1`처럼 선택 결과를 요약한다. 이는 이동·공격 위협을 같은 보드에서 읽게 하는 1차 구현이며 소환 기여도는 다음 단계다.

## UX 원칙

- 정답을 자동 추천하지 않고 판단 근거만 제공한다.
- 색만으로 구분하지 않고 텍스트 상태명을 함께 표시한다.
- 장식 추가보다 역할, 정보 우선순위, 행동 전후 피드백을 우선한다.
- 버튼명과 수치 등 읽어야 하는 정보는 실제 텍스트로 유지한다.

## 검증과 출시 상태

- 완료: 집중 테스트 3개 파일/44개, 전체 38개 파일/225개 테스트, `npm run build`, Impeccable 정적 검사 0건.
- 패키징: v0.8.2 `npm run dist`와 실행파일 배치는 이번 범위에서 실행하지 않음. 기존 v0.8.1 포터블은 유지.
- 미검증: 실제 플레이 화면, 450×800 좁은 화면, 저장 복귀, Steam 클라이언트·오버레이.
- 알려진 문제: Vite 약 1.59MB JavaScript 청크 경고. 이동 위험에는 아직 소환 기여도와 왕 위협 전후 차이가 포함되지 않는다. 복원 소스 v0.8.2와 Drive 실행파일 v1.1.0은 계보가 다르며 실행파일만으로 소스를 복원하지 않는다.
